# 프롬프트 스튜디오

학생의 과제·발표·학습을 위한 프롬프트 작성 도구입니다.

[프롬프트 스튜디오 사용하기](https://kongzzilab.kr/prompt-studio/)

`index.html`을 브라우저로 열면 바로 실행됩니다. 세 파일을 같은 폴더에 두세요. 설치, 빌드, API 키, 인터넷 연결은 필요하지 않습니다.

- `index.html`: 화면 구조와 접근성 레이블
- `styles.css`: 디자인과 PC·모바일 레이아웃
- `app.js`: 메뉴별 입력 항목·예시, 프롬프트 생성, 복사, 초기화

## 사용법

1. 사용자 프롬프트, 개인 맞춤 설정, 프로젝트 작업 지침 중 선택합니다.
2. 필요한 항목을 입력합니다. 추가 항목을 펼치면 더 자세한 조건을 입력할 수 있습니다.
3. 미리보기를 확인하고 전체 프롬프트 복사를 누릅니다.

입력하지 않은 항목은 결과에서 제외됩니다. 메뉴를 전환해도 작성 내용은 유지됩니다. 예시 불러오기와 초기화는 현재 메뉴에만 적용되며, 작성 중인 내용이 있으면 확인합니다.

입력 내용은 외부로 전송하거나 영구 저장하지 않습니다. 새로고침하거나 창을 닫으면 사라집니다. 자동 복사가 제한된 환경에서는 텍스트 전체 선택 후 직접 복사할 수 있습니다.

## 확장

`app.js`의 `MODES`에 입력 항목과 예시가 모여 있습니다. 각 항목은 `키, 제목, 설명, 입력 예시, 예시 내용` 순서입니다. `basic`은 기본으로 표시할 항목 수이며, 나머지는 추가 항목에 표시됩니다. `order`로 출력 순서를 별도로 지정할 수 있습니다.

일반 script 방식이므로 로컬 파일에서도 동작합니다. 향후 서버나 빌드 도구를 도입할 때 모듈로 분리할 수 있습니다.
